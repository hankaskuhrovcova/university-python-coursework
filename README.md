# University Python Coursework

Selected Python coursework completed as part of **Programming Fundamentals II and III** in the BSc Computing for Business programme at **Dublin City University**.

The repository contains a selection of exercises demonstrating my development of Python programming skills, including **object-oriented programming, recursion, data structures, set operations and algorithmic problem-solving**.

## Repository Structure

### `final_exam`

Selected programming problems completed during university assessments.

Examples include:

* finding pairs of numbers that meet a target sum
* recursively processing nested lists
* finding substrings within strings
* calculating the maximum area between two heights
* object-oriented modelling using Pizza and Order classes

### `object_oriented_programming`

Exercises focused on object-oriented programming concepts including:

* classes and objects
* inheritance
* method overriding
* operator overloading
* relationships between multiple classes

Examples include a bank account hierarchy and a student/module management exercise.

### `recursion`

Exercises covering recursive problem-solving, including:

* merging sorted lists
* traversing nested dictionaries
* processing strings and lists recursively

### `algorithms_and_sets`

Exercises using Python collections and algorithmic approaches, including:

* set-based pair searching
* Jaccard similarity
* set operations and data comparison

## Technologies and Concepts

* Python
* Object-Oriented Programming
* Recursion
* Lists, dictionaries, sets and tuples
* String manipulation
* Algorithmic problem-solving
* Basic time-complexity considerations
